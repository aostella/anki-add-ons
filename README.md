# Anki Add-ons

My collection of simple Anki add-ons.

## Add-ons list

* **[Add-ons Codes Exporter](./add-ons-codes-exporter)**: Easily copy all your installed add-on codes to share or backup.
* **[Today's Words Exporter](./today-words-exporter)**: Export all vocabulary words added today into a sentence separated by Japanese commas (`、`).
