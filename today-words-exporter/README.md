# Today's Words Exporter

A simple Anki add-on to copy all vocabulary words added today into a sentence separated by Japanese commas (`、`).

## What it does

If you learn Japanese words every day and want to review or generate practice sentences with them, this add-on automatically grabs all the cards you added today (or cards you select) and joins them into a clean comma-separated list like:

`憂鬱、形見、無難、耐久、増幅、砕く、道理、提示、不穏、徒歩`

## How to use

### From Main Menu
1. Open Anki.
2. Go to **Tools -> Export Today's Added Words** (or press `Ctrl+Alt+W` / `Cmd+Alt+W`).
3. Choose your preferred comma style (`、` or `, `).
4. Click **Copy to Clipboard**!

### From Card Browser
1. Open the Card Browser (`Browse`).
2. Select any notes you want.
3. Go to **Edit -> Export Words from Selected Notes**.
4. Click **Copy to Clipboard**!

## Features

- Works automatically on today's added cards (`added:1`).
- Works on selected notes inside the Card Browser.
- Switch between Japanese comma (`、`), Japanese comma with space (`、 `), or standard comma (`, `).
- Automatically removes duplicates and cleans extra tags.
