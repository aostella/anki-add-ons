# Add-ons Codes Exporter

A simple Anki add-on to copy all your installed add-on codes in one click!

## What it does

If you're moving to a new computer or backing up your Anki setup, this add-on lists all your installed add-on codes (like `12345, 67890`) so you can easily copy and paste them to install everything on another Anki app.

## How to use

1. Open Anki.
2. Go to **Tools -> Export Add-on Codes** (or press `Ctrl+Alt+E` / `Cmd+Alt+E`).
3. Click **Copy**!
4. Paste the codes into Anki (`Tools -> Add-ons -> Get Add-ons...`).

## Features

- Copy codes with commas (`12345, 67890`) or spaces (`12345 67890`).
- Quick shortcut: `Ctrl+Alt+E` (or `Cmd+Alt+E` on Mac).
- Shows all your installed add-ons in a list.
