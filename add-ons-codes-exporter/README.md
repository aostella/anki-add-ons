# Add-ons Codes Exporter

A simple Anki add-on to copy all your installed add-on codes in one click!

## What it does

If you're moving to a new computer or backing up your Anki setup, this add-on lists all your installed add-on codes so you can easily copy and paste them directly into Anki's **Install Add-on** dialog.

## How to use

1. Open Anki.
2. Go to **Tools -> Export Add-on Codes** (or press `Ctrl+Alt+E` / `Cmd+Alt+E`).
3. Click **Copy**!
4. Paste the codes directly into Anki (`Tools -> Add-ons -> Get Add-ons...`).

## Features

- Space-separated format (`12345 67890 112233`) ready for Anki's native installer.
- Quick shortcut: `Ctrl+Alt+E` (or `Cmd+Alt+E` on Mac).
- Shows all your installed add-ons in a list.
